# 교육청·사관 공통 DAY 워크북 (수학)

2021~2025년 교육청 학력평가와 사관학교 시험을 **회차별 DAY**로 나눠
한 DAY에 4점 5문항씩 묶은 워크북입니다.

| 파일 | 반 | 문항 |
|---|---|---|
| [교육청_사관_공통_PRO반.pdf](교육청_사관_공통_PRO반.pdf) | PRO반 | 어려운 4점 **14, 15, 20, 21, 22번** |
| [교육청_사관_공통_BASIC반.pdf](교육청_사관_공통_BASIC반.pdf) | BASIC반 | 쉬운 4점 **9, 10, 11, 12, 13번** |

각 PDF는 25일차 × 6쪽 = **150쪽**(A4)입니다.

## 쪽 구성

```
DAY 표지 1쪽 ─ 반 이름 · DAY 번호 · 총 소요시간 칸 · (시험, 문항 번호)
              [피드백] 5줄 표 (틀린 이유, 대응책, 새롭게 알게된 점 등)
              [빠른답안] 칸
문항 5쪽     ─ 학습체크 줄 (1. 구하는 것 확인 / 2. 조건 해석하기 / 3. 연결 설계 / 4. 피드백)
              #001 [2021학년도 3월 14번] … 아래는 풀이 공간
```

쪽 번호는 DAY 01 표지가 1쪽이고, DAY *n* 표지는 `6n − 5`쪽입니다 (DAY 21 → 121쪽).
문항 번호 `#001~#125`는 처음부터 끝까지 이어집니다.
PDF 책갈피에 DAY별·문항별 목차가 들어 있습니다.

## 문항과 정답 채우기

지금 PDF에는 **문항 본문과 정답이 들어 있지 않습니다.** 문항 자리는 점선 칸으로,
빠른답안은 손으로 적을 수 있게 빈칸으로 비워 두었습니다.
시험지 PDF(EBSi, 사관학교 홈페이지)에서 문항을 캡처해 넣고 다시 만들면 완성본이 됩니다.

1. 문항 이미지를 `problems/<시험>/<번호>.png` 로 저장합니다.
   ```
   problems/2021-3월/14.png
   problems/2022-사관/21.png
   ```
   (`.jpg`도 됩니다. 폴더 이름은 `answers.csv`의 `시험` 열과 같습니다.)
2. `answers.csv`에 정답을 적습니다. 1~15번은 `2`처럼 숫자만 적으면 `②`로 바뀝니다.
3. 다시 만듭니다.
   ```bash
   pip install reportlab
   python make_workbook.py            # 두 반 모두
   python make_workbook.py --only PRO # PRO반만
   ```

이미지가 없는 문항은 점선 칸 그대로, 정답이 없는 칸은 빈칸 그대로 남습니다.
기출 문항의 저작권은 각 교육청·사관학교에 있으니 개인 학습용으로만 쓰세요.
