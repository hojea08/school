# 수학 기출 DAY 워크북 (교육청·사관 / 평가원)

시험 한 회차를 **DAY 하나**로 나눠, 한 DAY에 4점 5문항씩(확률과 통계는 선택과목 8문항씩) 묶은 워크북입니다.
같은 형식으로 세 묶음을 만듭니다.

| 묶음 | 범위 | 파일 | 쪽수 |
|---|---|---|---|
| 교육청·사관 | 2021~2025년 교육청 학력평가 20회 + 2022~2026학년도 사관학교 5회 (25일차) | [PRO반](교육청_사관_공통_PRO반.pdf) · [BASIC반](교육청_사관_공통_BASIC반.pdf) | 150쪽 |
| 평가원 | 2027학년도 6월부터 2022학년도 수능까지 6월·9월 모의평가와 수능 17회 (17일차) | [PRO반](평가원_공통_PRO반.pdf) · [BASIC반](평가원_공통_BASIC반.pdf) | 102쪽 |
| 평가원 확률과 통계 | 2027학년도 6월부터 2020학년도 수능까지 6월·9월 모의평가와 수능 23회 (23일차, 212문항) | [확률과 통계](평가원_확률과%20통계.pdf) | 235쪽 |

- **PRO반**: 어려운 4점 **14, 15, 20, 21, 22번**
- **BASIC반**: 쉬운 4점 **9, 10, 11, 12, 13번**

- **확률과 통계**: 2022학년도부터 선택과목 「확률과 통계」 **23~30번**(단답형 29·30번).
  2020·2021학년도는 가형·나형 체제라 두 문제지에서 확률과 통계 문항을 골라 넣었습니다(일차마다 11~14문항).
  가형·나형에 같이 나온 문항은 가형 번호로 한 번만 넣고 꼬리표에 「가형 8번 · 나형 12번」처럼 둘 다 적습니다.
  고른 번호는 [스킬 문서](../.claude/skills/exam-day-workbook/references/subjects.md)의 「수학 2021학년도까지」에 있습니다.

PDF를 만드는 코드는 [DAY 워크북 스킬](../.claude/skills/exam-day-workbook/SKILL.md)에 있습니다.
이 폴더에는 묶음별 설정(`학평.json`, `평가원.json`, `평가원_확통.json`)과 빈 정답표, 빈 양식 PDF만 둡니다.

## 쪽 구성

```
DAY 표지 1쪽 ─ 반 이름 · DAY 번호 · 총 소요시간 칸 · (시험, 문항 번호)
              [피드백] 5줄 표 (틀린 이유, 대응책, 새롭게 알게된 점 등)
              [빠른답안] 칸
문항 5쪽     ─ 학습체크 줄 (1. 구하는 것 확인 / 2. 조건 해석하기 / 3. 연결 설계 / 4. 피드백)
              #001 [2021학년도 3월 14번] … 아래는 풀이 공간
```

쪽 번호는 DAY 01 표지가 1쪽이고, DAY *n* 표지는 `6n − 5`쪽입니다 (DAY 21 → 121쪽).
문항 번호(`#001~`)는 처음부터 끝까지 이어집니다.
PDF 책갈피에 DAY별·문항별 목차가 들어 있습니다.

## 문항과 정답 채우기

저장소의 PDF에는 **문항 본문과 정답이 들어 있지 않습니다.** 문항 자리는 점선 칸으로,
빠른답안은 손으로 적을 수 있게 빈칸으로 비워 두었습니다.
기출 문항의 저작권은 각 교육청·사관학교·한국교육과정평가원에 있어서, 이 공개 저장소에는
시험지와 문항이 들어간 완성본을 올리지 않습니다. 완성본은 아래 순서로 직접 만들어 개인 학습용으로만 쓰세요.
Claude Code에서는 "평가원 수학 워크북 만들어 줘"처럼 말하면 스킬이 이 순서를 따라 합니다.

```bash
pip install pymupdf reportlab pillow
SK=../.claude/skills/exam-day-workbook/scripts

# 1. 시험지와 정답표 받기 (평가원: 공식 게시판, 교육청·사관: 자료 블로그 — 스킬 문서 참고)
python $SK/sources.py kice-batch --area 수학 --years 2022-2027 --out exams

# 2. 문항 자르기 → problems/<시험>/<번호>.png, 그다음 모아보기로 전부 확인
python $SK/crop.py exams --items 9 10 11 12 13 14 15 20 21 22 --out problems
python $SK/sheets.py contact problems --out sheets

# 3. 정답 읽기 → 정답표 그림과 다른 출처로 한 번 더 확인
python $SK/answers.py exams --pdf official_ans.pdf --numbers 9-15 20-22 --render sheets/answers --csv answers_평가원.csv

# 4. 워크북 만들기
python $SK/make_workbook.py 평가원.json --out 완성본
python $SK/make_workbook.py 학평.json --out 완성본

# 확률과 통계: 2022학년도부터는 선택과목 쪽에서
python $SK/crop.py exams --items 23 24 25 26 27 28 29 30 --section "확률과 통계" --out problems
python $SK/answers.py exams --pdf official_ans.pdf --numbers 23-30 --section "확률과 통계" --csv answers_평가원_확통.csv
# 2021학년도까지는 가형·나형 문제지마다 (번호는 평가원_확통.json 의 exam_items)
python $SK/crop.py exams --only 2021-6월 --pdf prob_가형.pdf --prefix 가형 --items 4 8 13 17 19 22 27 29 --out problems
python $SK/answers.py exams --only 2021-6월 --pdf official_ans_가형.pdf --prefix 가형 --numbers 4 8 13 17 19 22 27 29 --csv answers_평가원_확통.csv
python $SK/make_workbook.py 평가원_확통.json --out 완성본
```

- 시험 폴더 이름은 `2021-3월`, `2022-사관`, `2027-6월`, `2026-수능`처럼 정답 CSV의 `시험` 열과 같습니다.
- 수능은 정답표가 홀수형 기준이니 **홀수형** 문제지를 씁니다(한 파일에 둘 다 있으면 홀수형만 자릅니다).
- 글자가 텍스트로 들어 있는 PDF만 자동으로 잘립니다. 스캔본이면 문항을 캡처해
  `problems/2021-3월/14.png`처럼 넣으면 됩니다.
- 정답 CSV에는 `2`처럼 숫자만 적어도 1~15번은 `②`로 바뀝니다.
- 2020·2021학년도 수능 정답표는 한 파일에 가형·나형이 있어 `--pdf official_ans.pdf --page 1`(가형 홀수형), `--page 3`(나형 홀수형)으로 읽습니다.
- 해설지는 시험 기관의 공식 해설이 있을 때만 따로 만듭니다. 평가원과 사관학교는 공식 해설이 없어 만들지 않습니다.

`exams/`, `problems/`, `solutions/`, `sheets/`, `완성본/`은 `.gitignore`에 들어 있어 실수로 올라가지 않습니다.
