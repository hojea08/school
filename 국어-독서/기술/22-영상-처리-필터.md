# 영상 처리 — 공간 필터링

> **한 줄 요약**
> 디지털 영상은 **밝기값의 2차원 배열**입니다.
> 작은 **커널(마스크)** 을 영상 위에 훑으며 **가중 평균**을 계산하면
> 잡음을 없애거나(**저역 통과**) 경계를 찾아낼 수 있습니다(**고역 통과**).
> 그리고 이 둘은 **서로 상충**합니다.

---

## 1. 디지털 영상의 구조

| 개념 | 내용 |
|---|---|
| **화소(pixel)** | 영상을 이루는 최소 단위. 각각 밝기값을 가짐 |
| **명암 영상** | 화소당 하나의 값 (보통 0~255. 0=검정, 255=흰색) |
| **컬러 영상** | 화소당 세 값(R, G, B) — 채널별로 같은 처리를 적용 |
| **해상도** | 화소의 개수. 많을수록 세밀 |

**영상에서의 '주파수'**

| | **저주파 성분** | **고주파 성분** |
|---|---|---|
| 의미 | 밝기가 **완만하게** 변하는 부분 | 밝기가 **급격히** 변하는 부분 |
| 해당하는 것 | 넓은 배경, 매끄러운 면 | **경계(edge), 세부 무늬, 잡음** ★ |

> **중요:** **경계와 잡음은 둘 다 고주파**입니다.
> 그래서 **잡음을 지우면 경계도 흐려집니다.** 이 제재의 핵심 긴장이 여기서 나옵니다.

---

## 2. 공간 필터링과 합성곱

> **커널(마스크)**: 작은 숫자 행렬(보통 3×3, 5×5).
> 이것을 영상의 각 화소에 **겹쳐 놓고**, 대응하는 값끼리 **곱해서 모두 더한 값**을
> 그 화소의 새 값으로 삼습니다. 이를 영상 전체에 반복합니다. → **합성곱(convolution)**

```
   영상 일부          커널(3×3)         계산
  ┌───┬───┬───┐    ┌───┬───┬───┐
  │ 10│ 20│ 30│    │1/9│1/9│1/9│    새 값 =
  ├───┼───┼───┤    ├───┼───┼───┤    (10+20+30+40+50+60+70+80+90)/9
  │ 40│ 50│ 60│ ⊛  │1/9│1/9│1/9│  = 50
  ├───┼───┼───┤    ├───┼───┼───┤    → 가운데 화소(50)를 이 값으로 대체
  │ 70│ 80│ 90│    │1/9│1/9│1/9│
  └───┴───┴───┘    └───┴───┴───┘
```

> **커널 계수의 합이 1이면 영상의 전체 밝기가 유지됩니다.** ★
> 합이 1보다 크면 밝아지고, 작으면 어두워집니다.
> (합이 **0**인 커널은 미분 필터로, 평탄한 부분이 0(검정)이 됩니다.)

### 경계 처리 (패딩)

영상의 가장자리에서는 커널이 **밖으로 삐져나갑니다.** 처리 방법:
- **0으로 채우기**(제로 패딩) — 가장자리가 어두워질 수 있음
- **가장자리 값 복제**
- **가장자리 화소는 처리하지 않음**

## 3. 저역 통과 필터 — 부드럽게 (잡음 제거)

> **주변 화소들의 평균을 취해** 급격한 변화를 완화합니다.

### 평균(박스) 필터

모든 계수가 같은 값(1/9 등). 단순하지만 **경계가 심하게 뭉개집니다.**

### 가우시안 필터

> **중앙에 큰 가중치, 멀어질수록 작은 가중치**를 주는 커널.

```
      1/16 × ┌ 1  2  1 ┐
             │ 2  4  2 │      ← 가운데가 가장 크고 대칭
             └ 1  2  1 ┘
```

- 평균 필터보다 **자연스럽게** 흐려집니다
- 커널 크기가 클수록 더 많이 흐려집니다

### 중간값(median) 필터 ★

> 주변 화소들을 **크기순으로 늘어놓고 가운데 값**을 취합니다.

| 특징 | 설명 |
|---|---|
| **비선형** | 곱하고 더하는 합성곱이 **아닙니다** (정렬해서 고르는 연산) |
| **소금-후추 잡음에 탁월** | 튀는 값(0이나 255)은 정렬하면 **양 끝으로 밀려나 선택되지 않습니다** |
| **경계 보존** | 평균과 달리 **없던 중간값을 만들어내지 않아** 경계가 덜 뭉개집니다 |

> **비교 감각:** 1, 2, 3, 4, **255**(튄 값) 에서
> 평균 = 53 (튄 값에 끌려감) / **중간값 = 3** (영향 없음).
> 이 차이가 중간값 필터의 강점입니다.

## 4. 고역 통과 필터 — 경계 찾기

> **경계 = 밝기가 급격히 변하는 곳 = 미분값이 큰 곳**

### 1차 미분 — 소벨(Sobel), 프리윗(Prewitt)

이웃 화소 간의 **차이**를 계산합니다.

```
  수직 경계 검출(x방향)        수평 경계 검출(y방향)
  ┌ -1  0  +1 ┐               ┌ -1 -2 -1 ┐
  │ -2  0  +2 │               │  0  0  0 │
  └ -1  0  +1 ┘               └ +1 +2 +1 ┘
```

- 좌우(또는 상하) 값의 **차이**를 구하므로, **평탄한 곳은 0**이 됩니다
- x방향과 y방향 결과를 합쳐 **경계의 세기와 방향**을 구합니다
- **커널 계수의 합이 0**입니다 (밝기를 더하는 게 아니라 **변화**를 재므로)

### 2차 미분 — 라플라시안

```
  ┌  0 -1  0 ┐
  │ -1  4 -1 │      (또는 8방향 버전)
  └  0 -1  0 ┘
```

- 변화율의 **변화율**을 봅니다. 경계에서 **부호가 바뀌는 지점(영교차)** 이 경계 위치
- 방향에 무관하게 경계를 검출하지만, **잡음에 매우 민감**합니다
  → 그래서 보통 **가우시안으로 먼저 흐린 뒤** 적용합니다 (LoG)

### 언샤프 마스킹 — 선명하게

> **선명한 영상 = 원본 + (원본 − 흐린 영상)**

"원본 − 흐린 영상"은 **흐려지면서 사라진 세부(고주파)** 입니다.
그것을 **원본에 다시 더해** 세부를 강조합니다.

> **이름이 헷갈리는 지점:** '언샤프(unsharp, 흐린) 마스크'를 쓰지만
> 결과는 **선명해집니다.** 흐린 영상을 **빼는 데** 쓰기 때문입니다.

## 5. 근본적 상충 ★

```
  잡음 제거(평활화)  ←────────────→  세부 보존(선명도)
       저역 통과                        고역 통과
```

| 처리 | 얻는 것 | 잃는 것 |
|---|---|---|
| 강한 평활화 | 잡음 감소 | **경계가 흐려짐**, 세부 상실 |
| 강한 선명화 | 세부 강조 | **잡음도 함께 증폭** |

> **경계와 잡음이 모두 고주파**이기 때문에 생기는 피할 수 없는 상충입니다.
> 그래서 **중간값 필터**나 **양방향 필터**처럼 "경계는 살리고 잡음만 지우는"
> 비선형 기법이 개발되었습니다.

---

## 6. 지문은 이렇게 전개된다

```
① 디지털 영상의 표현 — 화소와 밝기값
        ↓
② 공간 필터링과 커널(합성곱)의 원리
        ↓
③ 평활화 필터 — 잡음 제거
        ↓
④ 그러나 경계도 함께 흐려진다는 문제
        ↓
⑤ 중간값 필터 — 비선형, 경계 보존
        ↓
⑥ 미분 필터 — 경계 검출(소벨, 라플라시안)
        ↓
⑦ 언샤프 마스킹 / 상충 관계로 마무리
```

## 7. ⚠️ 선지 함정 포인트

1. **"잡음은 저주파 성분이다" → 틀림.**
   잡음은 **고주파**입니다. 그래서 저역 통과 필터로 제거합니다.

2. **"평활화 필터는 경계를 선명하게 만든다" → 틀림.**
   **경계도 함께 흐려집니다.** 이것이 평활화의 대가입니다.

3. **"중간값 필터는 주변 화소의 평균을 구한다" → 틀림.**
   **정렬해서 가운데 값**을 고릅니다. **평균이 아니며, 선형 연산도 아닙니다.**

4. **"커널 계수의 합이 0이면 전체 밝기가 유지된다" → 틀림.**
   밝기가 유지되려면 합이 **1**이어야 합니다.
   합이 0인 것은 **미분(경계 검출) 필터**의 특징입니다.

5. **"미분 필터는 잡음 제거에 효과적이다" → 반대입니다.**
   미분은 급격한 변화를 강조하므로 **잡음을 오히려 증폭**합니다.

6. **"라플라시안은 1차 미분 필터다" → 틀림.**
   **2차 미분** 필터입니다. 소벨·프리윗이 1차입니다.

7. **"언샤프 마스킹은 영상을 흐리게 만드는 기법이다" → 틀림.**
   이름과 달리 **선명하게** 만듭니다. 흐린 영상은 **빼기 위해** 만드는 중간 결과일 뿐입니다.

8. **"커널이 클수록 세부가 잘 보존된다" → 반대입니다.**
   평활화 커널이 클수록 **더 많이 흐려져** 세부가 더 사라집니다.

9. **"소금-후추 잡음에는 평균 필터가 가장 효과적이다" → 틀림.**
   극단적으로 튄 값은 **평균을 크게 왜곡**합니다.
   **중간값 필터**가 훨씬 효과적입니다.

10. **"경계는 밝기값이 큰 곳이다" → 틀림.**
    경계는 밝기가 **급격히 변하는 곳**입니다. 밝기의 **절대값**이 아니라 **변화량**입니다.

## 8. 확인 문제

**Q1.** 3×3 커널의 모든 계수가 1/9일 때, 이 필터의 효과는?

<details><summary>정답</summary>

주변 9개 화소의 **평균**을 취하는 **평활화(저역 통과) 필터**입니다.
잡음이 줄어드는 대신 **경계가 흐려집니다.**
계수의 합이 **1**이므로 영상의 전체 밝기는 유지됩니다.
</details>

**Q2.** 화소값이 `10, 12, 11, 255, 13`인 영역에서 평균 필터와 중간값 필터의 결과를 비교하시오.

<details><summary>정답</summary>

- **평균** = (10+12+11+255+13)/5 = **60.2** → 튄 값 255에 크게 끌려갑니다
- **중간값**: 정렬하면 10, 11, 12, 13, 255 → 가운데는 **12** → 튄 값의 영향을 받지 않습니다

→ **소금-후추 잡음 제거에는 중간값 필터가 훨씬 효과적**임을 보여줍니다.
</details>

**Q3.** 커널 계수의 합이 0인 필터는 어떤 종류이며, 평탄한 영역에서는 어떤 결과가 나오는가?

<details><summary>정답</summary>

**미분(고역 통과, 경계 검출) 필터**입니다.
평탄한 영역에서는 주변 화소값이 모두 같아 가중합이 **0**이 되므로 **검게** 나타납니다.
경계 부분에서만 큰 값이 나와 밝게 보입니다.
</details>

**Q4.** "잡음을 완전히 제거하면서 동시에 모든 세부를 보존하는 선형 필터를 설계할 수 있다."

<details><summary>정답</summary>

**틀림(X).** **잡음과 경계가 모두 고주파 성분**이기 때문에,
주파수만으로 둘을 구별할 수 없어 **원리적인 상충**이 존재합니다.
그래서 중간값 필터 같은 **비선형** 기법이 쓰이는 것입니다.
</details>

---

> **실전 주의**: 커널과 화소값이 함께 주어지면 **직접 계산하는 문제**가 나옵니다.
> 계산 자체는 곱하고 더하는 것뿐이니, **커널과 영상의 대응 위치**만 정확히 맞추세요.
> 그리고 **계수의 합**을 먼저 보면 그 필터의 성격(평활/미분)을 바로 알 수 있습니다.
