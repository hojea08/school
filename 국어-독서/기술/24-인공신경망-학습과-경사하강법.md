# 인공신경망 — 학습과 경사하강법

> **한 줄 요약**
> 신경망은 **가중치**라는 숫자 덩어리입니다.
> 학습이란 **예측이 정답에서 얼마나 벗어났는지(손실)** 를 재고,
> 손실이 **줄어드는 방향으로 가중치를 조금씩 밀어** 가는 과정입니다.

---

## 1. 인공 뉴런의 구조

```
   x₁ ──w₁──┐
   x₂ ──w₂──┤
   x₃ ──w₃──┼──→ Σ(가중합) + b(편향) ──→ 활성화 함수 f ──→ 출력
            │
   각 입력에 가중치를 곱해 모두 더하고, 편향을 더한 뒤,
   활성화 함수를 통과시킨다.
```

| 요소 | 역할 |
|---|---|
| **가중치(w)** | 그 입력을 **얼마나 중요하게** 볼 것인가. **학습으로 조정되는 대상** |
| **편향(b)** | 전체적인 문턱값을 조절. 역시 학습 대상 |
| **활성화 함수** | 가중합을 비선형으로 변환 |

### 활성화 함수와 비선형성 ★

| 함수 | 특징 |
|---|---|
| **시그모이드** | 출력을 0~1로 압축. **미분값의 최댓값이 0.25** → 층이 깊어지면 기울기 소실 |
| **ReLU** | 음수는 0, 양수는 그대로. 계산이 빠르고 **기울기 소실이 덜함** |
| **소프트맥스** | 출력층에서 여러 클래스의 확률로 변환 |

> **비선형 활성화 함수가 왜 반드시 필요한가? (출제 포인트)**
> 활성화 함수가 없거나 선형이면, **아무리 층을 쌓아도 하나의 선형 변환과 같습니다.**
> (선형 변환의 합성은 여전히 선형이니까요.)
> 즉 **층을 깊게 쌓는 의미가 사라집니다.**
> 비선형 함수가 있어야 복잡한 패턴을 표현할 수 있습니다.

## 2. 다층 신경망

```
  입력층 ──→ 은닉층 ──→ 은닉층 ──→ 출력층
             (특징을 단계적으로 추상화)
```

- 얕은 층: 단순한 특징(선, 모서리)
- 깊은 층: 복잡한 특징(모양, 대상)
- **층이 깊을수록 표현력이 커지지만, 학습이 어려워지고 과적합 위험도 커집니다**

---

## 3. 손실 함수 — 얼마나 틀렸는가

> **손실 함수**: 모델의 예측과 정답의 **차이를 하나의 수로** 나타낸 것.
> 이 값이 **작을수록 좋은 모델**입니다.

| 손실 함수 | 용도 |
|---|---|
| **평균제곱오차(MSE)** | 회귀 (연속값 예측) |
| **교차 엔트로피** | 분류 |

> **학습 = 손실 함수를 최소화하는 가중치를 찾는 일.**
> 그러면 문제가 **최적화 문제**로 바뀝니다.

---

## 4. 경사하강법 ★★★

### 착상

> 손실 함수를 **가중치에 대한 지형(골짜기)** 이라고 생각합니다.
> 우리는 안개 속에서 이 산을 내려가야 합니다.
> **발밑의 기울기**를 재고, **가장 가파르게 내려가는 방향**으로 한 걸음 내딛습니다.

### 갱신 규칙

> **w ← w − η × (∂L/∂w)**
>
> (새 가중치 = 기존 가중치 − 학습률 × 손실의 기울기)

| 기호 | 의미 |
|---|---|
| **∂L/∂w** | 가중치가 조금 변할 때 손실이 얼마나 변하는가 = **기울기(gradient)** |
| **η (학습률)** | 한 번에 얼마나 크게 움직일 것인가 = **보폭** |
| **−(음의 부호)** | 기울기의 **반대 방향**으로 가야 손실이 줄어듦 ★ |

> **왜 빼는가?** 기울기는 손실이 **증가하는** 방향을 가리킵니다.
> 우리는 줄이고 싶으므로 **반대 방향**으로 갑니다. 그래서 '경사**하강**'입니다.

### 학습률의 영향 — 자주 출제

| 학습률 | 결과 |
|---|---|
| **너무 크면** | 최솟값을 **건너뛰어 진동하거나 발산** |
| **너무 작으면** | 수렴이 **매우 느리고**, 얕은 국소 최솟값에 갇히기 쉬움 |
| 적당하면 | 안정적으로 수렴 |

### 배치 방식

| 방식 | 한 번 갱신에 쓰는 데이터 | 특징 |
|---|---|---|
| **배치(전체) 경사하강법** | 전체 데이터 | 방향이 정확하지만 **느리고 메모리 부담** |
| **확률적 경사하강법(SGD)** | 데이터 **1개** | 빠르지만 **진동이 심함**. 대신 국소 최솟값 **탈출에 유리** |
| **미니배치** | 일부 묶음(32, 64개 등) | **둘의 절충**. 실제로 가장 널리 쓰임 |

### 최적화의 어려움

| 문제 | 내용 |
|---|---|
| **국소 최솟값** | 전체 최솟값이 아닌 작은 골짜기에 갇힘 |
| **안장점** | 어떤 방향으로는 내리막, 다른 방향으로는 오르막인 평평한 지점 |
| **모멘텀** | 이전 이동 방향의 **관성**을 더해, 작은 골짜기를 지나쳐 가게 함 |

## 5. 오차 역전파 (backpropagation)

### 문제

> 은닉층 깊숙한 곳의 가중치가 최종 손실에 **얼마나 기여했는지**를 어떻게 아는가?
> 가중치가 수백만 개인데 하나씩 계산하면 불가능합니다.

### 해결: 연쇄 법칙을 이용한 역방향 계산

```
[순전파] 입력 ──→ 은닉층 ──→ 출력 ──→ 손실 계산
                                          │
[역전파]  ←── 기울기 ←── 기울기 ←── 오차 ─┘
         출력층에서 입력층 방향으로,
         연쇄 법칙으로 각 가중치의 기울기를 계산
```

| 특징 | 내용 |
|---|---|
| 원리 | **연쇄 법칙**(합성함수의 미분) |
| 방향 | **출력층 → 입력층** (순전파의 반대) |
| 효율 | 앞서 계산한 값을 **재사용**하여 한 번의 역방향 통과로 모든 기울기를 구함 |

> **역전파는 '학습 알고리즘'이 아니라 '기울기를 효율적으로 구하는 방법'입니다.**
> 실제로 가중치를 바꾸는 것은 **경사하강법**입니다. 이 역할 분담이 출제 포인트입니다.

### 기울기 소실 (vanishing gradient)

> 역전파로 기울기를 거슬러 올라갈 때, 층마다 **1보다 작은 값이 곱해지면**
> 입력층 쪽으로 갈수록 기울기가 **0에 가까워져** 학습이 멈춥니다.

- 시그모이드의 미분 최댓값이 **0.25**이므로, 층을 지날 때마다 최소 4분의 1로 줄어듭니다
- **해결책**: **ReLU** 사용(양수 구간 미분값이 1), 배치 정규화, 잔차 연결 등

## 6. 과적합과 일반화

| 개념 | 내용 |
|---|---|
| **과적합(overfitting)** | 학습 데이터에는 잘 맞지만 **새로운 데이터에는 성능이 나쁜** 상태 |
| **과소적합** | 학습 데이터조차 제대로 못 맞추는 상태 (모델이 너무 단순) |
| **일반화** | 처음 보는 데이터에서도 잘 작동하는 능력 = **진짜 목표** ★ |

> **학습의 목표는 학습 데이터의 손실을 0으로 만드는 게 아닙니다.**
> **보지 않은 데이터에서 잘 작동하는 것**입니다. 이 구분이 이 제재의 핵심 메시지입니다.

### 데이터 분할

| 집합 | 용도 |
|---|---|
| **학습 데이터** | 가중치를 갱신 |
| **검증 데이터** | 학습 중 성능을 점검하고 설정을 조절 |
| **시험 데이터** | 최종 성능 평가 (**학습에 절대 사용하지 않음**) |

### 과적합을 막는 방법

| 기법 | 원리 |
|---|---|
| **조기 종료** | 검증 손실이 다시 오르기 시작하면 학습 중단 |
| **드롭아웃** | 학습 중 일부 뉴런을 **무작위로 끔** → 특정 경로 의존을 막음 |
| **정규화(규제)** | 가중치가 너무 커지지 않도록 손실에 벌점 추가 |
| **데이터 증강** | 학습 데이터를 변형해 늘림 |

> **과적합의 신호:** 학습 손실은 계속 줄어드는데 **검증 손실은 늘어나기 시작**합니다.
> 이 교차 지점이 조기 종료의 기준입니다.

## 7. 지문은 이렇게 전개된다

```
① 인공 뉴런: 가중합 + 활성화 함수
        ↓
② 비선형 활성화 함수가 필요한 이유
        ↓
③ 학습이란 무엇인가 — 손실 함수의 최소화
        ↓
④ 경사하강법: 기울기의 반대 방향으로 이동
        ↓
⑤ 학습률의 영향 (너무 크면 / 너무 작으면)
        ↓
⑥ 역전파 — 기울기를 효율적으로 구하는 방법
        ↓
⑦ 기울기 소실과 ReLU
        ↓
⑧ 과적합과 일반화
```

## 8. ⚠️ 선지 함정 포인트

1. **"경사하강법은 기울기 방향으로 가중치를 이동시킨다" → 틀림.**
   **기울기의 반대 방향**입니다. 기울기는 손실이 **증가하는** 방향을 가리킵니다.
   갱신식의 **음(−) 부호**가 그 의미입니다.

2. **"학습률이 클수록 빠르고 정확하게 수렴한다" → 틀림.**
   너무 크면 최솟값을 **건너뛰어 진동하거나 발산**합니다.

3. **"역전파는 가중치를 갱신하는 알고리즘이다" → 부정확.**
   역전파는 **기울기를 계산**하는 방법이고,
   실제 갱신은 **경사하강법**이 합니다. 역할을 섞지 마세요.

4. **"역전파는 입력층에서 출력층 방향으로 진행된다" → 틀림.**
   **출력층에서 입력층 방향**입니다(순전파의 반대).

5. **"활성화 함수는 계산 속도를 높이기 위한 것이다" → 틀림.**
   **비선형성을 부여**하기 위한 것입니다.
   없으면 층을 아무리 쌓아도 **하나의 선형 변환**과 같아집니다.

6. **"학습 데이터의 손실이 0이면 가장 좋은 모델이다" → 틀림.**
   **과적합**의 전형적 징후입니다. 목표는 **일반화 성능**입니다.

7. **"기울기 소실은 학습률이 작아서 생긴다" → 틀림.**
   역전파 과정에서 **1보다 작은 미분값이 층마다 곱해져** 기울기가 0에 수렴하기 때문입니다.
   학습률과는 다른 원인입니다.

8. **"확률적 경사하강법이 배치 경사하강법보다 항상 정확한 방향으로 이동한다" → 틀림.**
   SGD는 데이터 하나만 보므로 **방향이 부정확하고 진동**합니다.
   대신 **빠르고 국소 최솟값 탈출에 유리**하다는 장점이 있습니다.

9. **"드롭아웃은 학습 속도를 높이는 기법이다" → 틀림.**
   **과적합을 막는** 기법입니다.

10. **"시험 데이터로 성능을 보며 설정을 조절한다" → 틀림.**
    그 역할은 **검증 데이터**입니다.
    시험 데이터를 보고 조절하면 **더 이상 공정한 평가가 아닙니다.**

## 9. 확인 문제

**Q1.** 경사하강법의 갱신식 `w ← w − η(∂L/∂w)` 에서 음(−) 부호가 필요한 이유는?

<details><summary>정답</summary>

기울기 ∂L/∂w는 손실 L이 **증가하는 방향**을 가리킵니다.
우리는 손실을 **줄이려** 하므로, 기울기의 **반대 방향**으로 이동해야 합니다.
그래서 빼는 것이며, 이 때문에 '경사**하강**'이라 부릅니다.
</details>

**Q2.** 활성화 함수 없이 층을 여러 개 쌓으면 어떤 문제가 생기는가?

<details><summary>정답</summary>

선형 변환을 여러 번 합성해도 결과는 **여전히 하나의 선형 변환**입니다.
따라서 층을 아무리 깊게 쌓아도 **단층 신경망과 표현력이 같아져**,
깊게 쌓는 의미가 사라집니다. **비선형** 활성화 함수가 필요한 이유입니다.
</details>

**Q3.** 학습을 계속하는데 학습 손실은 계속 줄고 검증 손실은 오르기 시작했다.
무슨 일이 일어나고 있으며 어떻게 대응하는가?

<details><summary>정답</summary>

**과적합**이 시작된 것입니다. 모델이 학습 데이터의 **잡음까지 외우기** 시작해
새로운 데이터에 대한 성능이 떨어지고 있습니다.

대응: **조기 종료**(검증 손실이 오르는 시점에서 학습 중단), 드롭아웃, 정규화, 데이터 증강 등.
</details>

**Q4.** "시그모이드 대신 ReLU를 쓰면 기울기 소실 문제가 완화된다."

<details><summary>정답</summary>

**맞음(O).** 시그모이드는 미분값의 최댓값이 **0.25**여서
역전파 시 층마다 곱해질 때 기울기가 급격히 작아집니다.
ReLU는 **양수 구간에서 미분값이 1**이므로 기울기가 그대로 전달되어
깊은 신경망에서도 학습이 가능해집니다.
</details>

> **손실 함수**(얼마나 틀렸나) → **역전파**(각 가중치의 책임 계산) → **경사하강법**(실제 수정),
> 이 3단 분업만 정확히 구분하면 대부분의 선지가 판별됩니다.
