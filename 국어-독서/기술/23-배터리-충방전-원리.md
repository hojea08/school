# 배터리 — 리튬 이온 전지의 충방전 원리

> **한 줄 요약**
> 배터리는 **산화-환원 반응의 전자 이동을 외부 회로로 우회시켜** 전기를 얻는 장치입니다.
> 리튬 이온 전지는 리튬 이온이 두 전극 사이를 **왕복하며 층 구조에 끼었다 빠지는** 방식이라
> 충전과 방전을 반복할 수 있습니다.

---

## 1. 기본 원리 — 산화·환원과 전자의 우회

| 개념 | 정의 |
|---|---|
| **산화** | 전자를 **잃는** 반응 |
| **환원** | 전자를 **얻는** 반응 |
| **산화제·환원제** | 자신은 환원되며 남을 산화시키면 산화제, 그 반대는 환원제 |

> **핵심 착상:** 산화되는 물질과 환원되는 물질을 **떼어 놓고**,
> 전자가 **외부 회로를 지나가게** 만들면 그 흐름이 **전류**가 됩니다.
> (직접 접촉하면 열만 나고 전기를 얻지 못합니다.)

### 전지의 구성

| 부품 | 역할 |
|---|---|
| **음극 / 양극** | 산화·환원 반응이 일어나는 전극 |
| **전해질** | **이온**이 이동하는 통로 (전자는 통과 못 함) ★ |
| **분리막** | 두 전극의 직접 접촉(단락)을 막되, **이온은 통과**시킴 |
| **집전체** | 전자를 모아 외부 회로로 보냄 |

> **전자는 외부 회로로, 이온은 전해질로.**
> 이 분업이 전지의 핵심입니다. 전해질이 전자를 통과시키면 **내부 단락**이 되어 전기를 못 씁니다.

### 용어 주의 ★

> **방전 시**: 산화가 일어나는 전극(전자를 내놓는 쪽)이 **음극(−)**,
> 환원이 일어나는 전극이 **양극(+)** 입니다.
>
> **충전 시에는 반응 방향이 반대가 됩니다.**
> 그래서 엄밀히는 산화/환원 전극의 이름이 뒤바뀌지만,
> 실무와 교과서에서는 **방전 기준으로 이름을 고정**해서 부릅니다.
> 지문이 어느 기준을 쓰는지 **반드시 확인**하세요. 함정으로 자주 쓰입니다.

## 2. 1차 전지와 2차 전지

| | **1차 전지** | **2차 전지** |
|---|---|---|
| 충전 | **불가** | **가능** |
| 반응 | 비가역적 | **가역적** |
| 예 | 알칼리 건전지 | **리튬 이온 전지**, 납축전지 |

> **2차 전지가 되려면 반응이 가역적이어야 합니다.**
> 즉 외부에서 전기를 넣어주면 **반응이 거꾸로 진행되어 원래 상태로 돌아가야** 합니다.

---

## 3. 리튬 이온 전지의 구조

| 전극 | 재료 | 구조 |
|---|---|---|
| **음극** | 주로 **흑연(층상 구조)** | 층 사이에 리튬이 **끼어들 수 있음** |
| **양극** | **리튬 금속 산화물** (LiCoO₂ 등) | 역시 층상 구조 |
| **전해질** | 리튬염을 녹인 유기 용매 | Li⁺가 이동 |
| **분리막** | 다공성 고분자 막 | 이온만 통과 |

### 삽입(intercalation)과 '록킹 체어' ★★★

> 리튬 이온이 전극 물질의 **층 사이에 끼어들었다(삽입) 빠져나오는(탈리)** 방식으로 작동합니다.
> 전극의 **골격 구조는 유지된 채** 리튬만 드나듭니다.

> **록킹 체어(rocking chair) 방식**: 리튬 이온이 두 전극 사이를 **흔들의자처럼 왕복**합니다.
> 리튬 금속이 석출되거나 전극 물질이 녹아 없어지는 게 아니라,
> **같은 리튬이 오갈 뿐**입니다. → 그래서 **수백~수천 회 재사용**이 가능합니다.

## 4. 방전 과정 (전기를 쓸 때)

```
[음극 · 흑연]                              [양극 · 금속산화물]
  Li가 산화                                     환원
  Li → Li⁺ + e⁻
       │      │
       │      └── e⁻ ──→ 외부 회로 ──→ (전구·모터) ──→ e⁻ ──┐
       │                                                    │
       └── Li⁺ ──→ 전해질 · 분리막 통과 ──────────────────→ Li⁺ + e⁻
                                                    양극 층간에 삽입
```

| 단계 | 내용 |
|---|---|
| ① | 음극(흑연) 층 사이의 리튬이 **산화** → Li⁺ + e⁻ |
| ② | **전자**는 외부 회로를 지나며 **일**을 함 (이것이 우리가 쓰는 전기) |
| ③ | **Li⁺** 는 전해질과 분리막을 통과해 양극으로 이동 |
| ④ | 양극에서 전자와 만나 **양극 물질의 층 사이에 삽입**됨 (환원) |

> **전자와 이온은 같은 목적지로 가지만 다른 길로 갑니다.** 이 그림이 이 제재의 핵심입니다.

---

## 5. 충전 과정 (전기를 넣을 때)

**외부 전원이 강제로 반대 방향으로 밀어붙입니다.**

```
외부 전원이 양극에서 전자를 빼앗음
     → 양극의 Li가 산화되어 Li⁺로 빠져나옴(탈리)
     → Li⁺ 가 전해질을 통해 음극으로 이동
     → 음극에서 전자와 만나 환원되어 흑연 층간에 삽입
```

| | **방전** | **충전** |
|---|---|---|
| Li⁺의 이동 방향 | 음극 → **양극** | 양극 → **음극** |
| 에너지 | 화학 → **전기** (내놓음) | 전기 → **화학** (저장) |
| 진행 | **자발적** | **비자발적** (외부 전원 필요) ★ |

> **충전은 자발적 반응이 아닙니다.** 외부에서 전기 에너지를 공급해
> **반응을 억지로 역방향으로 돌리는** 것입니다.

## 6. 전압·용량·내부 저항

| 개념 | 내용 |
|---|---|
| **기전력** | 두 전극의 **전위차**. 전극 재료가 결정 |
| **용량 (Ah)** | 얼마나 오래 전류를 낼 수 있는가. 리튬을 담을 수 있는 자리의 수에 비례 |
| **에너지 밀도** | 단위 질량·부피당 저장 에너지 (Wh/kg) |
| **내부 저항** | 전해질·전극의 저항. 전류가 클수록 **전압 강하**와 **발열**이 커짐 ★ |
| **C-rate** | 충방전 속도. 1C = 1시간에 완전 충방전하는 전류 |

> **내부 저항 때문에 실제 단자 전압은 기전력보다 낮습니다.**
> 그리고 그 차이만큼의 에너지가 **열**로 사라집니다.
> 급속 충전 시 배터리가 뜨거워지는 이유입니다.

### CC-CV 충전 방식

```
① 정전류(CC) 구간: 일정한 전류로 충전 → 전압이 서서히 상승
② 정전압(CV) 구간: 설정 전압에 도달하면 전압을 고정하고
                    전류를 점차 줄이며 마무리
```

> **왜 끝까지 정전류로 하지 않나?** 과전압이 걸리면 **전해질이 분해되고 구조가 손상**되기 때문입니다.
> 마지막은 천천히 채워야 안전합니다.

## 7. 열화(수명 감소)의 원인 ★

| 원인 | 내용 |
|---|---|
| **SEI 층 형성** | 첫 충전 때 전해질이 분해되어 음극 표면에 막이 생김. **초기에는 보호막 역할**을 하지만, 계속 두꺼워지면 **저항이 커지고 리튬이 갇혀** 용량이 줄어듦 |
| **리튬 도금(플레이팅)** | **저온**이나 **급속 충전** 시 리튬이 층간에 들어가지 못하고 **금속으로 석출**. 회수 불가능하며, 자라면 **분리막을 뚫어 단락** 위험 |
| **구조 붕괴** | 삽입·탈리를 반복하며 전극 물질의 층 구조가 서서히 무너짐 |
| **고온·과충전** | 부반응 가속, 심하면 **열폭주**(발열 → 반응 촉진 → 더 큰 발열)로 화재 |

> **급속 충전과 완전 방전이 수명에 나쁜 이유**가 여기에 있습니다.
> 특히 **리튬 도금**은 록킹 체어 구조가 깨지는 것이라 되돌릴 수 없습니다.

## 8. 지문은 이렇게 전개된다

```
① 화학 에너지 → 전기 에너지: 산화·환원과 전자의 우회
        ↓
② 전지의 구성 (전극, 전해질, 분리막) — 전자와 이온의 분업
        ↓
③ 1차 전지와 2차 전지 — 가역성
        ↓
④ 리튬 이온 전지의 구조와 삽입(록킹 체어)
        ↓
⑤ 방전 과정 / 충전 과정의 대칭
        ↓
⑥ 내부 저항과 발열, 충전 방식
        ↓
⑦ 열화 원인과 안전 문제
```

## 9. ⚠️ 선지 함정 포인트

1. **"전자가 전해질을 통해 이동한다" → 틀림.**
   전해질을 통과하는 것은 **이온(Li⁺)** 입니다.
   **전자는 외부 회로**로만 흐릅니다. 전해질이 전자를 통과시키면 배터리가 작동하지 않습니다.

2. **"충전은 자발적으로 일어나는 반응이다" → 틀림.**
   **외부 전원이 필요한 비자발적 반응**입니다. 자발적인 것은 **방전**입니다.

3. **"방전 시 리튬 이온은 양극에서 음극으로 이동한다" → 틀림.**
   방전 시에는 **음극 → 양극**입니다. 충전 시가 그 반대입니다.
   방향을 뒤집는 것이 최빈출 함정입니다.

4. **"리튬 이온 전지에서는 리튬 금속이 석출되면서 전기가 발생한다" → 틀림.**
   리튬은 **층 사이에 삽입·탈리**될 뿐입니다.
   금속으로 석출되는 것(**리튬 도금**)은 오히려 **고장·열화 현상**입니다.

5. **"충방전을 반복하면 전극 물질이 소모되어 사라진다" → 틀림.**
   전극의 **골격 구조는 유지**되고 리튬만 드나듭니다.
   그래서 재사용이 가능합니다(록킹 체어).

6. **"SEI 층은 항상 해로운 것이다" → 부정확.**
   **초기에는 전해질의 추가 분해를 막는 보호막** 역할을 합니다.
   문제는 **계속 두꺼워질 때**입니다.

7. **"내부 저항이 클수록 더 큰 전압을 낼 수 있다" → 틀림.**
   내부 저항은 **전압 강하와 발열**을 일으켜 성능을 **떨어뜨립니다.**

8. **"급속 충전은 배터리 용량을 늘린다" → 틀림.**
   오히려 **리튬 도금과 발열**로 **수명을 단축**시킵니다.

9. **"분리막은 이온도 전자도 모두 차단한다" → 틀림.**
   **전자(전극 간 직접 접촉)는 막고, 이온은 통과**시킵니다.

10. **음극·양극 이름의 기준을 확인하세요.**
    통상 **방전 기준**으로 고정해 부릅니다.
    "충전 시 음극에서 환원이 일어난다"는 서술은 이 기준에서 **맞는 말**입니다.

## 10. 확인 문제

**Q1.** 리튬 이온 전지가 방전될 때, 전자와 리튬 이온은 각각 어떤 경로로 이동하는가?

<details><summary>정답</summary>

- **전자**: 음극 → **외부 회로**(전구·모터 등을 거치며 일을 함) → 양극
- **리튬 이온(Li⁺)**: 음극 → **전해질과 분리막** → 양극

둘 다 음극에서 양극으로 가지만 **경로가 완전히 다릅니다.**
이 분리 덕분에 전자의 흐름을 전기로 사용할 수 있습니다.
</details>

**Q2.** '록킹 체어' 방식이라는 이름이 붙은 이유는?

<details><summary>정답</summary>

리튬 이온이 두 전극 사이를 **흔들의자처럼 왕복**하기 때문입니다.
리튬이 소모되거나 전극 물질이 변형되어 사라지는 것이 아니라,
**같은 리튬이 양쪽 전극의 층 사이를 오가며 삽입·탈리**되므로
충방전을 반복할 수 있습니다.
</details>

**Q3.** 겨울철 낮은 온도에서 급속 충전을 반복하면 왜 배터리 수명이 크게 줄어드는가?

<details><summary>정답</summary>

저온에서는 리튬 이온의 이동이 느려, 급속 충전으로 이온이 몰리면
**흑연 층 사이로 들어가지 못하고 표면에 금속 리튬으로 석출**됩니다(**리튬 도금**).
석출된 리튬은 **되돌릴 수 없어 용량이 영구적으로 감소**하며,
계속 자라면 **분리막을 뚫어 단락과 화재**를 일으킬 수 있습니다.
</details>

**Q4.** "충전과 방전은 서로 반대 방향의 반응이며, 둘 다 자발적으로 일어난다."

<details><summary>정답</summary>

**틀림(X).** 반대 방향인 것은 맞지만,
**방전만 자발적**입니다. 충전은 **외부 전원이 전기 에너지를 공급해야만**
일어나는 **비자발적** 반응입니다.
</details>

> 지문을 읽으며 **방전 화살표를 먼저 그리고, 충전은 전부 반대로** 표시해 두면
> 선지 대부분이 그 그림만으로 판별됩니다.
