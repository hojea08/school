# 과목별 구조

사용자가 다루는 과목은 수학과 직업탐구다. 다른 과목은 요청이 있을 때만 다룬다.

## 수학 (2022학년도 이후 공통 + 선택 체제)

| 번호 | 내용 | 형식 | 배점 |
|---|---|---|---|
| 1~8 | 공통(수학Ⅰ·Ⅱ) | 5지선다 | 2~3점 |
| 9~15 | 공통 | 5지선다 | 4점 |
| 16~19 | 공통 | 단답형 | 3점 |
| 20~22 | 공통 | 단답형 | 4점 |
| 23~30 | 선택: 확률과 통계 / 미적분 / 기하 | 23~28 5지선다, 29~30 단답형 | 2~4점 |

- 반: PRO반 `14 15 20 21 22`(어려운 4점), BASIC반 `9 10 11 12 13`(쉬운 4점). 공통 문항이라 선택과목과 상관없다.
- 설정에 `"short_answer": "16-22,29-30"`을 넣는다(정답 CSV에 숫자만 적어도 단답형을 원문자로 바꾸지 않게).
- 시험지는 A3 2단(842 × 1191pt). 낱문항만 있고 지문 묶음은 없다.
- 수능은 홀수형 문제지를 쓴다. 평가원 정답표는 1쪽이 홀수형이다. 2025학년도 수능 정답표는 글자가 없는 그림이라 눈으로 읽었다.
- 선택과목 23~30번은 같은 번호가 세 번 나온다. 필요하면 `crop.py --section 미적분`, `answers.py --section 미적분`.
- 교육청 학력평가(3·4·7·10월, 2024년부터 3·5·7·10월)와 사관학교 1차 시험도 같은 번호 체제다.
- 교육청 해설지: 첫머리에 정답표, 그다음 「14. [출제의도] …」로 문항별 해설. 2단 또는 3단 A4이고,
  선택과목 부분은 새 제목 상자와 「[확률과 통계]」 머리글로 시작한다. 숫자가 한글 수식 글꼴의 사용자 영역 글자
  (U+E034~E03D)로 들어 있는 경우가 많다. 스크립트가 풀어 읽는다.
- 사관학교 답안지: 「번호」 줄 아래 「정답」 줄이 공통(객관식·주관식)과 선택과목별로 이어진다. 해설은 없다.

## 직업탐구 (2022학년도 이후)

| 항목 | 내용 |
|---|---|
| 과목(게시판 zip 안 이름) | 성공적인 직업생활, 농업 기초 기술, 공업 일반, 상업 경제, 수산·해운 산업 기초, 인간 발달 |
| 문항 | 과목마다 20문항, 모두 5지선다, 2점·3점 |
| 시험지 | 과목마다 A3 2단 4쪽 PDF. 평가원 게시판에는 `직업탐구영역_문제지.zip`으로 올라온다 |
| 정답표 | `직업탐구영역_정답표.zip` 안 과목별 PDF. 제목에 「( 성공적인 직업생활 ) 과목」 |
| 지문 묶음 | 「[6~7] 다음은 기업가 A 씨의 일대기이다. 물음에 답하시오.」처럼 두 문항이 자료 하나를 같이 쓴다 |
| 해설 | 평가원 해설 없음 → 해설 PDF를 만들지 않는다 |

- 과목 하나로 워크북 하나를 만든다. 사용자가 반을 따로 정하지 않으면 `"전체": ["auto:1-20"]`로 20문항을 모두 넣는다.
  `auto`는 지문 묶음을 묶음째(`6-7`) 넣고 나머지는 낱문항으로 넣는다.
- 지문 묶음 번호를 낱개로 지정하면(`"6"`) `crop.py`가 「지문 묶음 안의 문항 → 지문이 빠짐」 경고를 낸다. 묶음이나 `auto`로 바꾼다.
- 설정에 `"subject": "성공적인 직업생활"`을 넣으면 꼬리표가 「[2027학년도 6월 성공적인 직업생활 6~7번]」이 된다.
- 받기: `sources.py kice-get --kind 모평 --year 2027 --month 6 --area 직업탐구 --subject "성공적인 직업생활" --out exams/2027-6월`
  (`kice-batch`도 `--subject`를 받는다).
- 정답: `answers.py exams --pdf official_ans.pdf --numbers 1-20` (정답표 모양은 평가원 다른 영역과 같다).
- 교육청 학력평가의 직업탐구 자료는 자료 블로그에 없을 수 있다. 찾지 못하면 사용자에게 알린다.

2027학년도 6월 성공적인 직업생활로 받기·자르기(18개: 낱문항 16개 + 묶음 6~7, 16~17)·정답 읽기를 확인했다.
