# 확인과 고치기

## 목차

- 자른 문항 확인
- 경고와 고치는 법
- 정답 확인
- 완성본 확인
- 지금까지 만난 문제

## 자른 문항 확인

`sheets.py contact problems --out sheets`가 시험마다 모아보기 PNG를 만든다. 전부 Read로 열어 문항마다 본다.

- **위**: 문항 번호 줄 전체가 있는가. 분수·지수·적분 기호 윗부분이 잘리지 않았는가.
- **아래**: 선택지 ①~⑤나 「[4점]」, 단답형 끝 문장까지 있는가. 다음 문항 번호가 끼지 않았는가.
- **그림·표·<보기> 상자**가 온전한가. 상자 테두리 네 변이 다 있는가.
- **지문 묶음**: 「[6~7] …」 머리글, 자료 전체, 묶음의 모든 문항이 있는가. 다음 단·다음 쪽으로 이어졌다면 그것도 들어왔는가.
- **군더더기**: 쪽 머리글 가로줄, 단 구분선, 쪽 번호, 「※ 확인 사항」 상자, 블로그 워터마크가 들어오지 않았는가.

의심스러우면 `sheets.py overlay exams problems --out sheets`로 시험지 쪽 위에 자른 상자를 그려 본다.

## 경고와 고치는 법

| 경고·증상 | 뜻 | 고치는 법 |
|---|---|---|
| `다음 단으로 이어질 수 있음` | 낱문항이 단 끝에서 끝나고 다음 단 첫 줄이 번호가 아님 | 모아보기로 보고, 정말 이어지면 `--flow` |
| `지문 묶음 안의 문항 → 지문이 빠짐` | [a~b] 묶음 안의 번호를 낱개로 지정 | 묶음(`6-7`)이나 `auto:1-20`으로 |
| `n번을 못 찾음` | 번호를 못 찾음(스캔본, 번호 모양이 다름) | 텍스트 PDF인지 확인, 해설은 `--marker` 정규식, 아니면 `--override` |
| 선택과목 번호가 엉뚱함 | 같은 번호가 과목마다 되풀이 | `--section 미적분` |
| 자른 영역이 틀림 | 위 방법으로 안 됨 | `--override` (아래) |

`--override` 파일(JSON)은 시험/라벨마다 자를 영역을 직접 준다. 좌표는 PDF pt, 쪽은 1부터.
여러 조각이면 위에서 아래로 쌓는다. 좌표는 `overlay` 그림이나 manifest.json의 `segments`를 고쳐서 만든다.

```json
{"2027-6월/14": [[3, 421.0, 520.0, 842.0, 1072.7], [4, 0, 150.0, 421.0, 300.0]]}
```

스캔본(글자 없는 PDF)은 자동으로 안 된다. 문항을 캡처해 `problems/<시험>/<라벨>.png`로 넣으면
문항 칸 폭(292pt)에 맞춰 들어간다. 크기 기록이 있는 그림(crop.py 결과)은 기록대로 놓인다.

## 정답 확인

1. `answers.py … --csv answers.csv --render sheets/answers --check <다른 출처>`를 돌린다.
2. `--render` 그림을 Read로 열어 요청한 번호의 값을 직접 읽고 CSV와 하나씩 맞춘다(5지선다는 원문자, 단답형은 숫자).
3. `--check` 결과가 「다름」이면 두 출처의 그림을 다 보고 판단한다. 「정답을 못 읽어 비교 못 함」이면 그 출처를 그림으로 본다.
4. `sources.py objections`로 이의신청 결과를 보고 정답 변경·복수 정답을 반영한다.
5. 그림으로만 된 정답표는 2번 방법으로 채우고, 다른 출처로 한 번 더 맞춘다.

`--check`에 쓸 출처: 블로그의 정답 파일, 교육청 해설지 첫머리 정답표. 평가원 시험을 블로그에서 받은
「정답, 해설」 파일은 대조용으로만 쓴다.

## 완성본 확인

- `make_workbook.py`가 끝에 알려 주는 「그림 없는 문항」「정답 빈칸」이 0개인지 본다.
- 쪽 수: 낱문항 k개짜리 반이면 `일차 수 × (1 + k)`쪽(나뉜 문항이 있으면 더 많다).
- `sheets.py pdf <완성본> --pages 1-7 --out sheets/pdf`로 표지와 문항 쪽 몇 장, 나뉜 문항이 있으면 그 쪽을 본다.
- 표지의 부제·빠른답안이 그 DAY의 시험·번호·CSV 값과 같은지 본다.

## 지금까지 만난 문제

| 문제 | 처리 |
|---|---|
| 수능 PDF 한 파일에 홀수형·짝수형 | 홀수형 쪽만 읽는다 |
| 「※ 확인 사항」 상자(글자가 「확인」「사항」으로 나뉘고 선 네 개로 그린 것 포함) | 같은 줄 글자를 모아 찾고 상자 윗변에서 자른다 |
| 두께 0인 선(상자 테두리)이 빠짐 | 선에 두께를 주어 영역에 넣는다 |
| 분수·지수가 글줄보다 위에 있어 잘림 | 번호 줄의 실제 윗변(수식 조각 포함)부터 자른다 |
| 쪽 머리글 가로줄·단 구분선이 찍힘 | 위로 넓히지 않고, 단 경계의 가는 세로선은 뺀다 |
| 3단 해설지 | 번호가 모이는 여백으로 단을 찾는다 |
| 해설지 선택과목 시작 쪽의 제목 상자, 「[확률과 통계]」 머리글이 앞 해설에 붙음 | 제목 상자를 머리글로 보고, 과목 머리글에서 멈춘다 |
| 한글 수식 글꼴 숫자(U+E034~E03D) | 정답 읽을 때 풀어 읽는다 |
| 정답표가 그림뿐(2025학년도 수능 수학) | 그림을 보고 직접 적는다 |
| 블로그 파일의 영역이 틀림 | 첫 쪽 글자로 확인하고 다른 출처를 쓴다 |
| 글자가 작은 해설지는 확대가 커서 DPI가 낮음 | PNG에 실제 크기를 적어 두고 그것을 쓴다 |
