# 워크북 형식

사용자가 사진으로 준 「교육청, 사관 공통 PRO반」 워크북을 그대로 옮긴 형식이다.
`make_workbook.py`가 이 치수로 그리므로 손댈 일은 없다. 사용자가 형식을 바꾸라고 할 때 참고한다.

## 목차

- 전체 구성
- DAY 표지
- 문항 쪽
- 글꼴과 색
- 바꿀 수 있는 것(설정)

## 전체 구성

- A4(595 × 842pt) 세로. 반마다 PDF 하나: `<file>_<반>.pdf` (예: `평가원_공통_PRO반.pdf`).
- 시험 한 회차가 DAY 하나. DAY마다 표지 1쪽, 그다음 문항마다 1쪽.
- 문항 번호 `#001`, `#002` …는 책 처음부터 끝까지 이어진다.
- 쪽 번호는 DAY 01 표지가 1쪽이다. 한 DAY에 낱문항 5개면 DAY *n* 표지는 `6n − 5`쪽이다.
- PDF 책갈피: DAY별(「DAY 01 · 2027학년도 6월」)과 그 아래 문항별(「#001 14번」).
- 한 쪽에 안 들어가는 문항(지문 묶음 등)은 문항 사이 넓은 빈 줄에서 나눠 다음 쪽에 이어 놓고,
  꼬리표에 「(계속)」을 붙인다. 높이가 12% 이내로 넘치면 나누지 않고 조금 줄여 한 쪽에 넣는다.

## DAY 표지

위에서부터 잰 y(pt). 왼쪽 여백 60, 오른쪽 끝 `595 − 58`.

| 요소 | 위치·모양 |
|---|---|
| 제목 「평가원 공통 PRO반」 | Bold 24pt, y 104 |
| 「DAY 01」 | Bold 32pt, y 170 |
| 총 소요시간 칸 | x 300 ~ 오른쪽 끝, y 142 ~ 172. 왼쪽 112pt는 회색(#e6e6e6) 칸에 「총 소요시간」(Medium 10pt) |
| 부제 「(2021학년도 3월 14,15,20,21,22번)」 | Medium 9.5pt, 진회색, y 196. 묶음은 「6~7, 8, 9」처럼 |
| 「[피드백]」 | Medium 8.5pt, y 252 |
| 피드백 표 | 위 266. 머리 24pt(회색 #d6d6d6, 「틀린 이유, 대응책, 새롭게 알게된 점 등 피드백」 Medium 7.5pt), 5줄 × 74pt, 왼쪽 번호 칸 26pt(#e6e6e6, 1~5) |
| 「[빠른답안]」 | Medium 8.5pt, 오른쪽 맞춤, y 706 |
| 빠른답안 칸 | x 285 ~ 오른쪽 끝, y 716, 높이 36. 답을 「③ / ① / ④ / 48 / 11」로. 묶음은 「6~7 ③⑤」 |
| 꼬리 | 왼쪽 반 이름(Medium 6.5pt), 가운데 쪽 번호(7pt), y 812 |

빠른답안: 5지선다 답은 원문자, 단답형은 숫자. 답이 길면 글자를 줄이고, 그래도 길면 칸을 왼쪽 끝까지 넓힌다.
정답이 하나라도 비면 손으로 적을 수 있게 칸만 「/」로 나눈다.

## 문항 쪽

왼쪽 여백 40, 오른쪽 끝 `595 − 40`.

| 요소 | 위치·모양 |
|---|---|
| 학습체크 줄 | y 40. 「✓학습체크 표시」(Bold 8pt, 파랑 #2f4f8f) 다음에 「1. 구하는 것 확인 □ │ 2. 조건 해석하기 □ │ 3. 연결 설계 □ │ 4. 피드백 □」를 줄 끝까지 고르게 |
| 파란 줄 | y 49, 1.6pt, #5a73a8 |
| 꼬리표 「#001 [2021학년도 3월 14번]」 | 「#001」 Bold 8pt 파랑 + 「[ … ]」 Regular 7.5pt 진회색, y 66 |
| 문항 그림 | 왼쪽 위(40, 76)부터, 실제 크기(본문 글자 약 10.2pt, 폭 최대 515pt, 높이 최대 720pt). 나머지는 풀이 공간 |
| 그림이 없을 때 | 폭 292 × 높이 210 점선 칸에 「2021학년도 3월 14번 / 문항 붙이는 자리」 |
| 꼬리 | 표지와 같음 |

## 글꼴과 색

- 글꼴: Pretendard Regular/Medium/Bold (SIL OFL 1.1, `assets/fonts/`).
- 색: 글자 #1f1f1f, 보조 #4a4a4a, 흐린 #9a9a9a, 선 #7d7d7d, 옅은 선 #c8c8c8, 표 머리 #d6d6d6, 옆 칸 #e6e6e6,
  파랑 #2f4f8f, 파란 줄 #5a73a8.

## 바꿀 수 있는 것(설정)

| 설정 | 기본값 | 쓰임 |
|---|---|---|
| `title` | (필수) | 표지 제목 앞부분. 뒤에 반 이름이 붙는다 |
| `file` | 제목에서 | PDF 이름 앞부분 |
| `classes` | (필수) | 반 이름 → 문항 지정 목록 |
| `schedule` | (필수) | DAY 순서의 시험 키 |
| `subject` | 없음 | 꼬리표·부제에 과목명(직업탐구 등) |
| `short_answer` | 없음 | 숫자로 적힌 답을 원문자로 바꾸지 않을 번호(수학 `16-22,29-30`) |
| `check_steps` | 사진의 네 칸 | 학습체크 네 칸 글자 |
| `feedback_head` | 사진의 문구 | 피드백 표 머리글 |

사진에 없는 요소를 더하거나 배치를 바꾸는 것은 사용자가 요청할 때만 한다.
