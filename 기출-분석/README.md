# 평가원 기출 제재 분석 (2027 수능 대비)

## ⚠️ 먼저 — 이 분석이 만들어진 방법과 그 한계

### 시도했으나 막힌 것

이 세션의 네트워크는 **조직 egress 정책**으로 외부 접근이 차단되어 있습니다.
문제지·해설 PDF를 내려받아 전수 대조하는 방식은 **불가능했습니다.**

| 경로 | 대상 | 결과 |
|---|---|---|
| `curl` | suneung.re.kr (평가원 수능 홈) | **CONNECT 403** |
| `curl` | kice.re.kr (평가원) | **CONNECT 403** |
| `curl` | ebsi.co.kr | **CONNECT 403** |
| `curl` | moe.go.kr (교육부) | **CONNECT 403** |
| `WebFetch` | namu.wiki (역대 독서 소재 전수 문서) | **EGRESS_BLOCKED** |
| `WebFetch` | wdown.ebsi.co.kr (회차별 해설 PDF) | **EGRESS_BLOCKED** |
| `WebFetch` | veritas-a.com, horaeng.com, blog.snacademy.co.kr | **EGRESS_BLOCKED** |
| `WebFetch` | ko.wikipedia.org | **EGRESS_BLOCKED** |
| **`WebSearch`** | — | ✅ **작동** |

### 실제로 사용한 방법

**WebSearch만으로** 회차별 정보를 수집하고, **같은 회차를 서로 다른 질의로 2회 이상 검색해 교차 검증**했습니다.
검색 요약이 **'학년도'와 '시행연도'를 혼동하는 사례가 실제로 여러 건 있었으므로**
(예: 플로리디·임대차·연료전지를 2026학년도 *수능* 연계로 잘못 묶은 요약이 있었고,
재검색 결과 **2026학년도 *6월 모평*** 연계로 확인됨), 교차 검증을 거치지 않은 항목은 그렇게 표시했습니다.

### 확인 강도 표기

| 표기 | 뜻 |
|---|---|
| **✅** | 서로 다른 검색에서 **일치**하거나, 문항 번호까지 특정된 항목 |
| **△** | **단일 출처** 요약에만 근거. 방향은 맞을 가능성이 높으나 세부는 재확인 권장 |
| **?** | **확인하지 못함**. 추정하지 않고 빈칸으로 둠 |

> **?로 남긴 칸을 추측으로 메우지 않았습니다.** 기출 제재는 하나가 틀리면
> 대비 방향 전체가 어긋나므로, 모르는 것은 모른다고 적는 편이 낫습니다.

### 직접 확인하시려면

차단은 이 실행 환경의 정책이지 사이트의 문제가 아닙니다. 개인 PC에서는 아래가 모두 열립니다.

- **한국교육과정평가원 수능 홈** `suneung.re.kr` → 자료마당: 역대 수능·모평 **문제지와 정답 원본**
- **EBSi** `ebsi.co.kr` → 기출문제: 회차별 **해설지 PDF**, **EBS 연계 내역 분석**
- 나무위키 「대학수학능력시험/국어 영역/출제된 독서 소재」 → **역대 제재 전수 목록** (가장 포괄적)

## 가장 중요한 결론 세 줄

1. **직전 학년도(2026)에 계약법이 두 번 소모**됐습니다 — 6평 임대차 계약 갱신, 수능 보증 계약.
   원래 1순위로 뒀던 **계약법 노트의 우선순위를 크게 낮춰야** 합니다.
2. **2025학년도 수능이 '기계 학습과 확산 모델'을 이미 썼습니다.**
   **인공신경망 노트도 우선순위를 크게 낮춰야** 합니다.
3. 반대로 **생명과학(면역·신경·유전자)은 2023학년도 수능 이후 공백**이 길어
   **우선순위를 올려야** 합니다.
