# 영어 독서 — 과학철학: 반증 가능성과 과학적 합의

> **한 줄 요약**
> 과학을 과학답게 만드는 것은 **증명**이 아니라 **반증될 수 있음**입니다(포퍼).
> 그러나 실제 과학은 한 번의 반증으로 무너지지 않고,
> **공동체의 합의**를 통해 느리게 바뀝니다(쿤).

---

## 1. 반증 가능성 (Falsifiability)

### 핵심 논지

> **문제:** 아무리 많은 관찰도 보편 법칙을 **증명하지 못합니다.**
> 흰 백조를 백만 마리 봐도 "모든 백조는 희다"가 증명되지 않습니다.
> 그러나 **검은 백조 한 마리면 반박됩니다.** → **귀납의 비대칭성**

> **포퍼의 답:** 과학과 비과학을 가르는 기준은 **검증 가능성이 아니라 반증 가능성**이다.
> 좋은 이론은 **틀릴 수 있는 방식을 스스로 명시**한다.

| | **과학적 이론** | **비과학적 주장** |
|---|---|---|
| 예측 | **구체적이고 위험한** 예측 | 모호해서 무엇이든 맞아떨어짐 |
| 반례 | **무엇이 반례가 될지 말할 수 있음** | 어떤 관찰로도 반박 불가 |
| 설명력 | 설명하지 **못하는** 것이 있음 | **모든 것**을 설명함 ← 오히려 약점 ★ |

> **가장 반직관적인 대목:** "모든 것을 설명하는 이론"은 **강점이 아니라 결함**입니다.
> 무엇으로도 반박할 수 없다면, 그 이론은 세계에 대해 **아무것도 주장하지 않는** 것과 같습니다.

**자주 나오는 확장 논점**
- **애드혹 수정(ad hoc modification)**: 반례가 나올 때마다 예외 조항을 붙여 이론을 구하는 것.
  이렇게 하면 반증 가능성이 줄어들어 **과학성이 떨어집니다**
- 과학은 **진리의 축적이 아니라 오류의 제거**로 나아갑니다
- 어떤 이론도 **최종적으로 참임이 입증되지는 않고**, 다만 **아직 반박되지 않았을** 뿐입니다

### 핵심 어휘

| 영어 | 한국어 |
|---|---|
| falsifiability / refutable | 반증 가능성 / 반박 가능한 |
| verify, confirm | 검증하다, 확증하다 |
| demarcation | (과학과 비과학의) 구획 |
| conjecture and refutation | 추측과 반박 |
| bold / risky prediction | 대담한 / 위험한 예측 |
| rule out | 배제하다 |
| ad hoc modification | 임시방편적 수정 |
| tentative, provisional | 잠정적인 |
| corroborate | (이론을) 뒷받침하다 |
| accommodate any outcome | 어떤 결과든 수용해 버리다 |

### 전형적 문장 패턴

> **A theory that explains everything explains nothing.**
> 모든 것을 설명하는 이론은 **아무것도 설명하지 않는다.**

> **No number of observations can prove a universal law, but a single counterexample can refute it.**
> 아무리 많은 관찰도 보편 법칙을 증명할 수 없지만, **단 하나의 반례가 그것을 반박할 수 있다.**

> **Scientific knowledge is not certain; it is merely the best tested so far.**
> 과학적 지식은 확실한 것이 아니라, 다만 **지금까지 가장 잘 시험된 것**일 뿐이다.

## 2. 과학적 합의는 어떻게 형성되는가

### 핵심 논지

> 실제 과학은 포퍼의 그림처럼 단정하게 작동하지 않습니다.
> 예측이 빗나가도 과학자들은 **이론을 즉시 버리지 않습니다.**
> 측정 오류를 의심하거나, 보조 가정을 수정하거나, 문제를 보류합니다.

**왜 그런가**
- 어떤 예측도 **이론 하나만으로** 도출되지 않습니다 — 측정 도구, 보조 가설이 함께 쓰입니다
- 그래서 예측이 빗나가도 **어디가 틀렸는지 특정할 수 없습니다** (뒤엠-콰인 논제)
- **더 나은 대안이 없으면** 결함 있는 이론이라도 계속 씁니다

### 쿤의 패러다임 (자주 함께 등장)

| 단계 | 내용 |
|---|---|
| **정상 과학** | 하나의 **패러다임** 안에서 퍼즐을 푸는 활동. 패러다임 자체는 의심하지 않음 |
| **변칙 사례 누적** | 설명되지 않는 사례가 쌓임. 처음에는 무시되거나 미해결로 남겨짐 |
| **위기** | 변칙이 감당할 수 없이 쌓임 |
| **과학 혁명** | 새 패러다임으로 **전환**. 점진적 축적이 아니라 **불연속적 교체** |

> **공약 불가능성(incommensurability)**: 서로 다른 패러다임은 용어의 의미와 문제의 기준이 달라
> **같은 잣대로 비교하기 어렵습니다.**

### 합의를 만드는 사회적 장치

| 장치 | 역할 |
|---|---|
| **동료 평가(peer review)** | 개인의 편향을 공동체가 걸러냄 |
| **재현(replication)** | 다른 연구자가 같은 결과를 얻는지 확인 |
| **경쟁하는 연구 집단** | 서로의 오류를 찾아낼 유인이 있음 |

> **핵심 메시지:** 과학의 객관성은 **개별 과학자가 편향 없기 때문이 아니라,
> 서로를 검증하는 제도가 작동하기 때문에** 생깁니다. ★
> (인지과학 편의 '확증 편향'과 이어지는 대목입니다.)

### 핵심 어휘

| 영어 | 한국어 |
|---|---|
| consensus | 합의 |
| paradigm, paradigm shift | 패러다임, 패러다임 전환 |
| normal science | 정상 과학 |
| anomaly | 변칙 사례 |
| incommensurable | 공약 불가능한 |
| peer review | 동료 평가 |
| replication / reproducibility | 재현 / 재현 가능성 |
| auxiliary assumption | 보조 가정 |
| accumulate gradually vs abrupt shift | 점진적 축적 vs 급격한 전환 |
| self-correcting | 자기 교정적인 |
| a matter of degree | 정도의 문제 |

### 전형적 문장 패턴

> **Science is self-correcting not because scientists are unbiased, but because they check one another.**
> 과학이 자기 교정적인 것은 과학자들이 편향되지 않아서가 아니라,
> **서로를 검증하기 때문이다.**

> **Anomalies are rarely fatal on their own; they accumulate until the framework can no longer contain them.**
> 변칙 사례는 그 자체로 치명적인 경우가 드물다.
> **틀이 더는 담아낼 수 없을 때까지 쌓인다.**

> **A failed prediction tells us that something is wrong, but not what.**
> 예측의 실패는 무언가 틀렸다는 것은 알려주지만, **무엇이 틀렸는지는 알려주지 않는다.**

## 3. 이 주제의 전형적 지문 전개

```
① 통념: "과학은 증거를 쌓아 진리를 증명한다"
                  ↓
② 문제 제기: 귀납의 한계 (관찰은 증명할 수 없다)
                  ↓
③ 포퍼의 답: 반증 가능성
                  ↓
④ 그러나 실제 과학은 그렇게 작동하지 않는다 (however)
                  ↓
⑤ 쿤 / 공동체 / 합의 형성
                  ↓
⑥ 결론: 과학의 힘은 확실성이 아니라 자기 교정 능력에 있다
```

## 4. ⚠️ 함정 포인트

1. **"과학은 이론을 증명한다" → 이 주제군에서는 항상 오답 방향입니다.**
   과학은 **증명하지 않고**, 다만 **아직 반박되지 않은 상태**를 유지합니다.
   `prove`, `establish with certainty` 가 들어간 선지를 의심하세요.

2. **"모든 것을 설명하는 이론이 우수하다" → 정반대입니다.**
   이 주제에서는 **결함**입니다. 가장 반직관적이라 가장 자주 출제됩니다.

3. **"과학적 지식은 확실하다" vs "과학은 믿을 수 없다" — 둘 다 오답입니다.**
   논지는 **"잠정적이지만 가장 잘 검증된 것"** 이라는 중간 지점입니다.
   극단 어느 쪽으로도 밀지 마세요.

4. **포퍼와 쿤을 섞지 마세요.**
   - **포퍼**: 반증 가능성 = 과학의 **기준**(규범적)
   - **쿤**: 실제 과학은 패러다임 안에서 작동한다(**기술적**)
   지문이 둘을 **대비**시키고 있는지 확인하세요.

5. **"과학자 개인이 객관적이다" → 오답 방향.**
   논지는 **개인이 아니라 제도가 객관성을 만든다**는 것입니다.

6. **"패러다임 전환은 점진적 축적이다" → 틀림.**
   쿤의 요점은 **불연속적이고 급격한 교체**입니다.
   `gradual accumulation`이 들어가면 의심하세요.

## 5. 확인 문제

**Q1.** 빈칸에 가장 적절한 것은?
`A theory that can accommodate any possible observation is, paradoxically, ________.`
① the most powerful ② scientifically weak ③ easily verified ④ widely accepted

<details><summary>정답</summary>

**②**. `paradoxically`(역설적으로)가 결정적 단서입니다.
어떤 관찰도 수용해 버리는 이론은 **반증 불가능**하므로, 이 주제에서는 **과학적으로 취약**합니다.
①은 상식적으로 그럴듯해 보이지만, `paradoxically`와 충돌합니다.
</details>

**Q2.** 포퍼가 말하는 '귀납의 비대칭성'을 설명하시오.

<details><summary>정답</summary>

아무리 많은 **긍정 사례**도 보편 법칙을 **증명하지 못하지만**,
**단 하나의 반례**는 그것을 **반박하기에 충분**합니다.
(흰 백조 백만 마리 ≠ 증명 / 검은 백조 한 마리 = 반박)
이 비대칭성 때문에 과학의 기준이 검증이 아니라 **반증 가능성**이 되어야 한다는 것입니다.
</details>

**Q3.** "예측이 빗나갔는데도 과학자들이 이론을 즉시 폐기하지 않는" 이유는?

<details><summary>정답</summary>

어떤 예측도 **이론 하나만으로** 도출되지 않고, **측정 도구와 여러 보조 가정**이 함께 쓰이기 때문입니다.
따라서 예측이 빗나가도 **정확히 어느 부분이 틀렸는지 특정할 수 없습니다.**
또한 **더 나은 대안이 없으면** 결함 있는 이론이라도 계속 사용합니다.
</details>

**Q4.** `Science is self-correcting not because scientists are unbiased, but because they check one another.`
이 문장의 함의는?

<details><summary>정답</summary>

과학의 객관성은 **개인의 덕성(편향 없음)이 아니라 공동체의 제도**(동료 평가, 재현, 경쟁)에서 나온다는 것입니다.
개별 과학자도 확증 편향에서 자유롭지 않지만, **서로를 검증하는 구조**가 오류를 걸러냅니다.
</details>
