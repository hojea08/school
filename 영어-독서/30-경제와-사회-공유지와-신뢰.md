# 영어 독서 — 경제와 사회: 공유지, 신뢰, 넛지

> **한 줄 요약**
> 개인에게 합리적인 선택이 **모두에게 나쁜 결과**를 낳는 상황이 있습니다(공유지의 비극).
> 그것을 푸는 것은 시장이나 국가만이 아니라 **신뢰와 규범**이기도 하며,
> 강제 대신 **선택 환경의 설계**로 행동을 바꾸는 방법도 있습니다(넛지).

---

## 1. 공유지의 비극 (The Tragedy of the Commons)

### 핵심 구조 ★

> 누구나 이용할 수 있고, **한 사람이 쓰면 남이 못 쓰는** 자원이 있습니다.
> 각자에게는 **더 많이 쓰는 것이 이득**입니다 — 이득은 온전히 내 것이고,
> **고갈의 비용은 모두에게 나뉘기** 때문입니다.
> 모두가 그렇게 행동하면 자원은 **파괴됩니다.**

```
   개인의 이득  =  전부 나에게
   고갈의 비용  =  모두에게 분산
        ↓
   개인에게 합리적 → 집단에게 파국
```

**재화의 네 종류 (자주 표로 나옵니다)**

| | **배제 가능** (돈 내야 씀) | **배제 불가능** |
|---|---|---|
| **경합적** (쓰면 줄어듦) | 사유재 (사과) | **공유자원** (어장, 목초지) ← 비극의 대상 |
| **비경합적** | 클럽재 (유료 방송) | 공공재 (국방, 등대) |

> **공유자원이 문제인 이유:** 배제할 수 없어서 **아무나 쓸 수 있는데**,
> 경합적이어서 **쓰면 줄어듭니다.** 이 조합이 비극을 만듭니다.

### 고전적 두 해법과 그 한계

| 해법 | 방식 | 한계 |
|---|---|---|
| **사유화** | 자원을 나눠 소유권을 부여 | 어장·대기처럼 **나눌 수 없는** 자원이 많음 |
| **국가 규제** | 중앙에서 할당·감시 | **감시 비용**이 크고, 현지 사정을 모름 |

### 오스트롬의 제3의 길 ★★★ — 반전 지점

> **엘리너 오스트롬**은 실제 공동체들이 **사유화도 국가 개입도 없이**
> 공유자원을 **수백 년간 성공적으로 관리해 온 사례들**을 찾아냈습니다.
> (스위스 알프스 목초지, 일본의 입회림, 필리핀 관개 시설, 연안 어촌 등)

**성공한 공동체의 공통 조건 (자주 출제)**

| 조건 | 내용 |
|---|---|
| **경계의 명확성** | 누가 이용자이고 자원의 범위가 어디까지인지 분명함 |
| **규칙의 현지 적합성** | 외부에서 내려온 규칙이 아니라 **현지 조건에 맞는** 규칙 |
| **참여적 의사결정** | 규칙의 영향을 받는 사람들이 **규칙 제정에 참여** |
| **감시** | 이용자들이 **서로를 감시**하거나, 이용자에게 책임지는 감시자 |
| **점층적 제재** | 첫 위반은 가볍게, 반복되면 무겁게 |
| **저렴한 분쟁 해결** | 갈등을 빠르고 싸게 푸는 장치 |
| **조직할 권리의 인정** | 외부 권력이 공동체의 자치를 인정 |

> **핵심 메시지:** 비극은 **필연이 아닙니다.**
> 사람들은 소통하고 규칙을 만들고 서로를 감시할 수 있습니다.
> 고전 모형이 비관적이었던 이유는 **소통과 제도를 가정에서 배제**했기 때문입니다.

### 핵심 어휘

| 영어 | 한국어 |
|---|---|
| commons / common-pool resource | 공유지 / 공유자원 |
| depletion, overexploitation | 고갈, 남획·과다이용 |
| free rider | 무임승차자 |
| rival / excludable | 경합적인 / 배제 가능한 |
| collective action problem | 집단행동 문제 |
| self-governance | 자치 |
| enforce, sanction | 집행하다, 제재하다 |
| monitor one another | 서로 감시하다 |
| individually rational, collectively disastrous | 개인적으로 합리적, 집단적으로 파국적 |
| inevitable | 불가피한 |

### 전형적 문장 패턴

> **What is rational for each is ruinous for all.**
> 각자에게 합리적인 것이 **모두에게는 파멸적**이다.

> **The benefits are private while the costs are shared.**
> 이득은 사적인 반면 **비용은 공유된다.**

> **The tragedy is not inevitable; it is the outcome of a particular set of assumptions.**
> 비극은 **불가피한 것이 아니라**, 특정한 가정들이 낳은 결과다.

## 2. 신뢰와 사회적 자본 (Trust and Social Capital)

### 핵심 논지

> **사회적 자본** = 사람들 사이의 **네트워크, 규범, 신뢰**.
> 이것이 높은 사회는 **거래 비용이 낮고 협력이 쉽습니다.**

**왜 경제적으로 중요한가**
- 신뢰가 없으면 모든 거래에 **계약, 감시, 법적 장치**가 필요합니다 → **비용 폭증**
- 신뢰는 **감시 비용을 대체**하는 자산입니다
- 그래서 사회적 자본은 **생산성에 직접 영향**을 미칩니다

**두 종류의 사회적 자본 ★**

| | **결속형** (bonding) | **가교형** (bridging) |
|---|---|---|
| 대상 | **같은 집단 안**(가족, 동향, 동문) | **다른 집단 사이** |
| 효과 | 강한 유대, 즉각적 지원 | **새로운 정보와 기회**, 사회 통합 |
| 위험 | **배타성**, 외부인 배제, 집단 이기주의 | (상대적으로 낮음) |

> **자주 나오는 반전:** 사회적 자본이 **항상 좋은 것은 아닙니다.**
> 결속형만 강하면 **폐쇄적이고 배타적인 사회**가 됩니다.
> 지문은 종종 **"어떤 종류의 신뢰인가"** 를 문제 삼습니다.

**일반화된 신뢰 vs 특정한 신뢰**

| | **일반화된 신뢰** | **특정한 신뢰** |
|---|---|---|
| 대상 | **모르는 사람 일반** | 아는 사람 |
| 사회적 효과 | 낯선 사람과의 거래·협력 가능 → **경제 발전과 상관** | 좁은 범위에 국한 |

**자주 나오는 확장 논점**
- 신뢰는 **쌓기는 느리고 무너지기는 빠릅니다** (비대칭성)
- 제도에 대한 신뢰와 사람에 대한 신뢰는 **서로를 강화**합니다
- 인과 방향 문제: **신뢰가 번영을 낳는가, 번영이 신뢰를 낳는가** — 지문이 이 문제를 제기할 수 있습니다

### 핵심 어휘

| 영어 | 한국어 |
|---|---|
| social capital | 사회적 자본 |
| bonding / bridging | 결속형 / 가교형 |
| generalized trust | 일반화된 신뢰 |
| transaction cost | 거래 비용 |
| norm of reciprocity | 호혜의 규범 |
| civic engagement | 시민 참여 |
| cohesion | 결속, 응집 |
| erode / build up | 침식되다 / 쌓이다 |
| exclusionary | 배타적인 |
| lubricant (for cooperation) | (협력의) 윤활유 |
| correlate with ≠ cause | ~와 상관이 있다 ≠ 원인이다 |

### 전형적 문장 패턴

> **Trust functions as a lubricant: where it is present, cooperation costs less.**
> 신뢰는 **윤활유처럼 작동한다.** 신뢰가 있는 곳에서는 협력의 비용이 줄어든다.

> **Not all social capital is benign; tight-knit groups can exclude as effectively as they include.**
> 모든 사회적 자본이 이로운 것은 아니다.
> **긴밀한 집단은 포용하는 만큼 효과적으로 배제할 수 있다.**

> **Trust takes years to build and moments to destroy.**
> 신뢰는 쌓는 데 수년이 걸리지만 **무너지는 데는 한순간**이다.

## 3. 넛지 (Nudge)

### 핵심 논지

> 사람들의 행동을 바꾸는 방법은 **금지와 유인(보상·처벌)만이 아닙니다.**
> **선택의 구조를 다시 설계**하는 것만으로도 행동이 크게 달라집니다.

**넛지의 정의 (요건이 중요합니다) ★**

| 요건 | 내용 |
|---|---|
| ① | 선택 **환경(구조)** 을 바꾼다 |
| ② | **선택의 자유가 유지**된다 — 금지가 아니다 |
| ③ | **경제적 유인을 크게 바꾸지 않는다** — 세금·보조금이 아니다 |
| ④ | 예측 가능한 방식으로 행동을 유도한다 |

> **세 요건을 모두 만족해야 넛지입니다.**
> 흡연 금지 = 넛지 아님(금지). 담뱃세 인상 = 넛지 아님(유인 변경).
> **담뱃갑 경고 그림, 장기기증 옵트아웃, 구내식당 배치** = 넛지.

**대표 수단**

| 수단 | 예 |
|---|---|
| **기본값(default)** | 연금 자동 가입, 장기기증 옵트아웃 — 가장 강력 |
| **사회 규범 정보** | "이웃의 80%가 이미 실천하고 있습니다" |
| **현저성(salience)** | 중요한 정보를 눈에 띄게 |
| **단순화** | 신청 절차를 줄임 |
| **피드백** | 실시간 에너지 사용량 표시 |

**왜 작동하는가**: 사람들의 **현상유지 편향, 손실 회피, 주의의 한계**를 이용하기 때문입니다.
(국어 **행동경제학** 편과 그대로 연결됩니다.)

**비판 (지문 후반부에 자주)**
- **조작(manipulation)** 아닌가 — 이성적 설득이 아니라 편향을 이용함
- **누가 '더 나은 선택'을 정하는가** — 설계자의 가치 판단이 개입
- **자율성 침해** 우려
- 효과가 **과장되었다**는 실증적 반론도 있음

> 옹호 측의 이름: **자유주의적 개입주의(libertarian paternalism)**.
> "선택의 자유는 지키면서(자유주의) 더 나은 선택을 돕는다(개입주의)"는 결합입니다.
> 지문은 종종 이 이름 자체가 **모순처럼 보인다**는 점을 짚고 시작합니다.

### 핵심 어휘

| 영어 | 한국어 |
|---|---|
| nudge | 넛지, 살짝 밀기 |
| choice architecture | 선택 설계 |
| default option | 기본 선택지 |
| opt in / opt out | 가입 선택 / 탈퇴 선택 |
| libertarian paternalism | 자유주의적 개입주의 |
| coercion / mandate / ban | 강제 / 의무화 / 금지 |
| incentive | 유인 |
| steer, prompt | 유도하다, 자극하다 |
| autonomy | 자율성 |
| inertia, status quo bias | 관성, 현상유지 편향 |

### 전형적 문장 패턴

> **A nudge alters behavior without forbidding any options or significantly changing economic incentives.**
> 넛지는 **어떤 선택지도 금지하지 않고 경제적 유인을 크게 바꾸지도 않으면서** 행동을 바꾼다.

> **There is no such thing as a neutral choice architecture.**
> **중립적인 선택 설계란 존재하지 않는다.** (어떻게 배치하든 영향을 미치므로)

> **Critics argue that nudges work precisely because they bypass deliberation.**
> 비판자들은 넛지가 **숙고를 우회하기 때문에** 효과가 있다고 지적한다.

## 4. 이 주제의 전형적 지문 전개

```
① 문제 상황 제시 (자원 고갈 / 협력 실패 / 낮은 참여율)
                  ↓
② 표준적 진단과 처방 (사유화 / 규제 / 유인 설계)
                  ↓
③ 반전 — 실제로는 다르게 작동한다 (however, yet)
                  ↓
④ 대안적 설명 (자치 제도 / 신뢰 / 선택 설계)
                  ↓
⑤ 조건과 한계 (언제 작동하고 언제 실패하는가)
                  ↓
⑥ 비판 또는 균형 잡힌 결론
```

## 5. ⚠️ 함정 포인트

1. **"공유지의 비극은 불가피하다" → 이 주제군에서는 오답 방향입니다.**
   오스트롬을 다루는 지문의 논지는 **"비극은 필연이 아니다"** 입니다.
   `inevitable`, `unavoidable`이 들어간 선지를 의심하세요.

2. **"해결책은 사유화 또는 국가 규제뿐이다" → 이 이분법을 깨는 것이 지문의 목적입니다.**
   **제3의 길(공동체 자치)** 이 주제문인 경우가 많습니다.

3. **"사회적 자본은 많을수록 좋다" → 단정하면 틀림.**
   **결속형만 강하면 배타적**이 됩니다. 지문은 대개 **종류**를 구별합니다.

4. **넛지의 요건을 빠뜨리지 마세요.**
   **금지나 강한 유인 변경은 넛지가 아닙니다.**
   "넛지는 사람들이 선택하지 못하게 만든다" 같은 선지는 정의 위반입니다.

5. **`correlation ≠ causation`.**
   신뢰와 번영은 **상관**이 있지만, 지문이 **인과**를 단정했는지 확인하세요.
   `is associated with`와 `causes`는 다릅니다.

6. **"무임승차 문제는 사람들이 이기적이어서 생긴다" → 부분적.**
   구조적 원인은 **"이득은 사적이고 비용은 공유된다"** 는 **유인 구조**입니다.
   도덕성의 문제로만 환원하면 지문의 논지를 놓칩니다.

7. **양적 표현의 강도에 주의하세요.**
   이 주제군은 `can`, `may`, `under certain conditions`, `tend to` 같은 **한정어**를 많이 씁니다.
   선지가 `always`, `never`, `only`로 강화되어 있으면 대개 오답입니다.

## 6. 확인 문제

**Q1.** 빈칸에 가장 적절한 것은?
`In a commons, the benefits of overuse accrue to the individual while the costs are ________.`
① immediately visible ② borne by everyone ③ legally enforced ④ easily reversed

<details><summary>정답</summary>

**②**. 공유지의 비극의 핵심 구조는
**"이득은 사적으로 귀속되고 비용은 모두에게 분산된다"** 는 유인의 비대칭입니다.
`while`이 **대조**를 예고하므로, `to the individual`과 대비되는 표현이 들어가야 합니다.
</details>

**Q2.** 오스트롬의 연구가 고전적 '공유지의 비극' 모형에 던진 반론은?

<details><summary>정답</summary>

고전 모형은 이용자들이 **소통하지 못하고 규칙을 만들 수 없다**고 가정했지만,
현실의 많은 공동체는 **사유화나 국가 개입 없이도** 자치 규칙과 상호 감시를 통해
공유자원을 **수백 년간 지속가능하게 관리**해 왔습니다.
따라서 **비극은 필연이 아니라 특정 가정의 산물**이라는 것입니다.
</details>

**Q3.** 결속형(bonding) 사회적 자본이 지나치게 강할 때의 위험은?

<details><summary>정답</summary>

**배타성**입니다. 내부 결속이 강한 집단은 **외부인을 효과적으로 배제**하며,
집단 이기주의나 폐쇄성으로 이어질 수 있습니다.
사회 전체의 통합과 새로운 정보·기회의 흐름에는 **가교형(bridging)** 자본이 필요합니다.
</details>

**Q4.** 다음 중 넛지에 해당하는 것은?
① 흡연을 법으로 금지하는 것 ② 담뱃세를 두 배로 올리는 것
③ 장기기증을 기본값으로 하고 원하면 거부하게 하는 것 ④ 기부금에 세액공제를 주는 것

<details><summary>정답</summary>

**③**. 넛지는 ① **선택의 자유를 유지**하고(거부 가능),
② **경제적 유인을 크게 바꾸지 않아야** 합니다.
①은 금지(강제), ②와 ④는 경제적 유인의 변경이므로 넛지가 아닙니다.
③은 **기본값(default)** 을 바꿔 현상유지 편향을 이용하는 전형적 넛지입니다.
