# 영어 독서 배경지식

## 왜 영어는 예측이 더 잘 맞나

수능 영어 지문은 대부분 **영어권 학술 교양서·논문에서 발췌**됩니다.
그래서 소재가 **학계에서 이미 널리 논의된 주제**에 몰려 있고,
논증 전개 방식도 **몇 가지 정형**을 따릅니다.

국어 독서보다 **주제 예측의 적중률이 높은** 이유입니다.

---

## 국어 노트와 형식이 다른 이유

영어에서 어려운 건 **개념**이 아니라 **문장**입니다.
같은 내용을 알아도, 그것이 영어의 어떤 표현으로 나타나는지 모르면 못 읽습니다.

그래서 이 노트들은 다음에 집중합니다.

| 항목 | 내용 |
|---|---|
| **핵심 논지** | 그 주제에서 지문이 말하려는 것 (한국어) |
| **핵심 어휘** | 그 주제에 반드시 나오는 단어·표현 (영어-한국어) |
| **전형적 문장 패턴** | 실제 지문에 나오는 형태의 영어 문장 + 해석 |
| **논증 전개 구조** | 통념 제시 → 반박 → 근거 → 재진술 등의 흐름 |
| **함정 포인트** | 빈칸·주제·순서 문제에서 틀리는 지점 |

## ⚠️ 국어와 똑같은 원칙이 적용됩니다

배경지식은 **첫 문장에서 당황하지 않기 위한 것**입니다.
빈칸 추론과 주제 추론의 정답은 **언제나 지문 안의 논리 관계**로 결정됩니다.

특히 영어에서 위험한 함정:

> 배경지식으로 아는 "일반적으로 맞는 말"을 정답으로 고르는 것.
> 빈칸의 정답은 **참인 명제**가 아니라 **그 자리에 들어가야 하는 명제**입니다.

지문이 `however`, `yet`, `rather than`으로 **통념을 뒤집었다면**,
정답도 뒤집힌 쪽입니다. 상식대로 고르면 틀립니다.
